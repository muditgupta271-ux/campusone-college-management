# CampusOne College Management System

Flask + SQLite college project with admin, student and teacher dashboards, account creation and password recovery. Run locally with `pip install -r requirements.txt` and `python app.py` (local demo password: `demo123`). Free Render deployment uses Gunicorn, an ephemeral SQLite database, an environment-provided admin password and a private session key. Database records may disappear when the service restarts or redeploys. Configure ADMIN_PASSWORD privately in Render. Do not commit database files or secrets. Use fictional records only until the application has undergone a full security review. Existing local data is not migrated automatically.
